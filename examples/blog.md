# Blog Generation Examples

## Generate a blog post
```
/cgenius blog generate "How AI is transforming sales in 2026" --size medium --tone professional --keywords "AI, sales, automation"
```

## Check status
```
/cgenius blog status abc123-task-id
```

## Resume a failed blog
```
/cgenius blog resume abc123-task-id
```

## Regenerate a specific section
```
/cgenius blog regenerate abc123-task-id 2
```

## List all blogs
```
/cgenius blog list
```
