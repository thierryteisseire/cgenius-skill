# Publish & Schedule Examples

## Schedule a blog post
```
/cgenius publish schedule content-id-123 --platform blog --date 2026-05-20T10:00:00Z
```

## Schedule a social post
```
/cgenius publish schedule content-id-456 --platform social --date 2026-05-18T14:00:00Z
```

## List scheduled content
```
/cgenius publish list --status scheduled
```

## List published content
```
/cgenius publish list --status published
```
