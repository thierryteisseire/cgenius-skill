# Proposal Examples

## Generate a proposal
```
/cgenius proposal "Acme Corp" --services "Content marketing, SEO" --budget "50k" --duration "3 months"
```

## Run full proposal pipeline
```
/cgenius proposal-pipeline "TechStart Inc" --industry "Technology" --budget "50k" --timeline "3 months" --services "Content marketing, SEO" --goals "Increase organic traffic 200%"
```
