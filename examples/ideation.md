# Content Ideation Examples

## Create an ideation
```
/cgenius ideate create "Content marketing trends for SaaS in 2026" --priority high
```

## List ideations
```
/cgenius ideate list --status new
```

## Run analysis on an ideation
```
/cgenius ideate analyze ideation-id-123
```

## Generate content from ideation
```
/cgenius ideate generate ideation-id-123 --type blog
```
